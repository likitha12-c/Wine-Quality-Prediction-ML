# Wine Quality Prediction Using Statistical Analysis and Machine Learning

## Project Overview

This project focuses on analyzing and predicting wine quality using statistical analysis and machine learning techniques.

The objective is to understand the relationship between the physicochemical properties of wine and its quality. The project uses laboratory measurements to identify patterns, perform statistical analysis, build predictive models, and present findings through an interactive dashboard.

## Problem Statement

A wine-production company wants to understand how the chemical properties of wine influence its quality. This project aims to develop a data-driven solution to analyze historical wine data, identify important factors affecting quality, predict wine quality, and support better business decisions.

## Dataset Information

**Dataset:** UCI Wine Quality Dataset

**Source:** UCI Machine Learning Repository

**Dataset Type:** White Wine Dataset

- Total Records: 4,898
- Input Features: 11
- Target Variable: Quality

### Dataset Attributes

| Attribute | Description |
|---|---|
| Fixed Acidity | Fixed acid concentration |
| Volatile Acidity | Volatile acid concentration |
| Citric Acid | Citric acid concentration |
| Residual Sugar | Sugar remaining after fermentation |
| Chlorides | Chloride concentration |
| Free Sulfur Dioxide | Free sulfur dioxide level |
| Total Sulfur Dioxide | Total sulfur dioxide level |
| Density | Density of wine |
| pH | Acidity or alkalinity measure |
| Sulphates | Sulphate concentration |
| Alcohol | Alcohol percentage |
| Quality | Numerical wine quality score |

- Collect and understand the wine quality dataset.

- Prepare a final analytical report with findings and recommendations.
